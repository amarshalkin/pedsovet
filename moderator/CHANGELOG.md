# moderator changelog

## [0.4.0] — 2026-11-06

- Шаблон отчёта по умолчанию (`assets/templates/default/`): `профиль.md` для модели и `шаблон.md` для чтения. На шаге `init` после создания папок плагин спрашивает: шаблон по умолчанию или свой.
- Профиль отчёта (`03-отчет/шаблон/профиль.md`) вместо сводки «Структура (для плагина)»: строгий скелет, правила полей (все пояснения шаблона), оформление, обезличенные примеры, машинные проверки. Для своего шаблона профиль составляется автоматически и показывается на подтверждение; тот же шаблон, что по умолчанию, распознаётся.
- `scripts/lint-report.mjs`: проверка чистовика дня и собранного отчёта по правилам профиля (обязательные поля, незаполненные места, жирный в тексте, пунктуация списков, объём комментариев); `build` исправляет найденное до показа чистовика и до сборки docx.
- Чек-лист строится из профиля; `report-writing.md` оставлен для правил, не зависящих от шаблона.
- `evals/evals.json`: три оценочных сценария на выдуманных данных.

## [0.3.0] — 2026-10-16

- `init` в конце выводит короткую инструкцию по работе с плагином (`references/user-guide.md`): фиксация во время программы, два шага на каждый день в `build`, слова-сигналы, варианты `/moderator:build день N | итоги | оцифровка | сборка`, где что лежит. Та же инструкция — в README.
- `build`: комментарии к черновику можно присылать несколькими сообщениями; чистовик дня собирается только по явному сигналу «готово», переход к следующему дню — по «дальше».

## [0.2.0] — 2026-10-15

- Фактическое расписание дня: отчёт строится по слотам расписания каждого дня, а не по плановой программе.
  - `capture` распознаёт карточку расписания дня (день — по дате в шапке), принимает её как есть, без сверки и подтверждений; изменения в течение дня («блок перенесли») применяются со слов модератора.
  - Пока расписание начавшегося дня не получено, `capture` напоминает о нём после каждой фиксации, первым.
  - `build` перед черновиком дня без расписания спрашивает: пришлёте расписание или строить по программе.
  - Новые блоки из расписания включаются в отчёт по правилам отбора; спорные помечаются `uncertain` и уточняются в вопросах к черновику.
- `status.mjs`: пробел `no-day-schedule`, поле `scheduleMissing`.
- Новый справочник `references/day-schedule.md`.

## [0.1.1] — 2026-10-14

- `artifact-digitizer`: description во frontmatter переведён в блочный YAML-скаляр (`|`) — строгий парсер claude.ai не принимал блоки `<example>` с нулевым отступом.

## [0.1.0] — 2026-10-14

- Первая версия: команды `/moderator:init`, `/moderator:capture`, `/moderator:build`.
- Агент `artifact-digitizer` для параллельной оцифровки флипчартов, карточек и стикеров.
- Скрипты: конвертация фото, сопоставление фото с блоками программы по времени съёмки,
  извлечение текста, статус папки, сборка `.docx` со стилями шаблона.
